# Sonance AutoLogin — инструкция

Sonance AutoLogin — форк [Sonance3](https://github.com/MrSimmo/sonance3), который избавляет от ввода адреса музыкального сервера и длинного пароля пультом Samsung.

Сервер может находиться **где угодно**: дома, на VPS, за доменом или на локальном IP. Для автоподключения сейчас поддерживается Navidrome и совместимые с ним серверы Subsonic. Jellyfin пока остаётся с обычной авторизацией, как в оригинальном Sonance3.

## Собираем на Mac или Linux

Нужны Node.js 18+, bash, zip, unzip и perl. При первой сборке может понадобиться интернет, чтобы npx загрузил минификаторы Sonance.

~~~bash
git clone https://github.com/vbrekher/sonance3-autologin.git
cd sonance3-autologin
node scripts/build-personal.mjs
~~~

Скрипт спросит:

1. Полный адрес Navidrome, например `https://music.example.com` или `http://192.168.1.20:4533`.
2. Имя пользователя.
3. Движок воспроизведения — HTML5 Audio (по умолчанию) или AVPlay.
4. Пароль. Его можно вставить из менеджера паролей; в Терминале символы не отображаются. Запрос пароля идёт последним.

Ничего из этого не придётся набирать на телевизоре.

После сборки в папке `dist` появятся:

- `Sonance-AutoLogin-Oblong.wgt` — широкая иконка.
- `Sonance-AutoLogin-Square.wgt` — квадратная иконка.

Выбери **один** файл и установи через [Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung). Если программа предложит переподписать пакет — соглашайся. Sonance AutoLogin устанавливается отдельно от обычного Sonance.

## Если музыка не запускается

На Samsung UE43DU7100UXUA с Tizen 9 исходный Sonance3 через AVPlay открывал библиотеку, но музыка оставалась на 00:00. HTML5 Audio заработал. Поэтому персональный сборщик предлагает HTML5 по умолчанию.

Это подтверждено на одной модели — совместимость со всеми Samsung и всеми кодеками не обещаем.

## Важно: пароль в WGT

Пароль вводится **локально**, не загружается на GitHub и не отправляется нам. Но он **вшивается в готовый WGT**, поэтому любой, кому достанется пакет, сможет его извлечь.

**Не прикладывай персональные WGT к Issues, не загружай в Releases и не коммить в репозиторий.** Лучше создай отдельного пользователя Navidrome для телевизора.
