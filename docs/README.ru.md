# Sonance AutoLogin — инструкция на русском

**Музыка на Samsung TV без ввода длинного адреса и пароля пультом.**

Sonance AutoLogin — это форк [Sonance3](https://github.com/MrSimmo/sonance3). Ты собираешь приложение под свою учётную запись Navidrome на компьютере, устанавливаешь WGT на телевизор и сразу открываешь музыкальную библиотеку.

Сервер может находиться где угодно: дома, на VPS, за собственным доменом. **Bunny не обязателен.** Вводить данные на телевизоре не нужно.

## Сборка на Mac

Нужны Node.js 18+, bash, zip, unzip, perl и доступ к интернету при первой сборке.

Открой Терминал и введи:

~~~bash
git clone https://github.com/vbrekher/sonance3-autologin.git
cd sonance3-autologin
npm run build:personal
~~~

Если `npm` или `node` не установлены — сначала поставь Node.js с [nodejs.org](https://nodejs.org/).

Сборщик задаст четыре вопроса:

1. **Navidrome URL** — полный адрес, например `https://music.example.com` или `http://192.168.1.20:4533`.
2. **Username** — имя пользователя Navidrome.
3. **Playback** — нажми Enter, чтобы оставить HTML5 Audio, или введи `A` для AVPlay.
4. **Password** — последний вопрос. Вставь пароль через Cmd+V и нажми Enter. Символы не будут видны — это нормально.

После сборки получишь два файла:

| Файл | Для чего |
| --- | --- |
| `dist/Sonance-AutoLogin-Oblong.wgt` | Широкая иконка на экране Samsung |
| `dist/Sonance-AutoLogin-Square.wgt` | Квадратная иконка |

Установить нужно **один** из них.

## Как установить на Samsung

1. Открой раздел **Apps** на телевизоре, перейди в настройки приложений.
2. Набери `12345` пультом. Включи Developer Mode, укажи IP компьютера, с которого будешь устанавливать приложение, затем перезагрузи телевизор.
3. Убедись, что телевизор и компьютер подключены к одной сети.
4. Скачай [Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung/releases) на компьютер.
5. Выбери телевизор, открой установку собственного **WGT**, укажи созданный файл. При необходимости разреши Apps2Samsung переподписать приложение.
6. На телевизоре открой **Sonance AutoLogin**. Адрес и данные входа уже будут в программе.

Подробности и ссылки на официальную документацию Samsung: [Installation](INSTALLATION.md).

## Почему HTML5 по умолчанию?

В оригинальном Sonance3 используется Samsung AVPlay. На **UE43DU7100UXUA с Tizen 9** библиотека открывалась, но музыка оставалась на 00:00. HTML5 Audio заработал, а после исправления переключения треков песни стали автоматически воспроизводиться одна за другой.

Это проверено на одной модели телевизора, не на всех Samsung. AVPlay тоже можно выбрать при сборке.

## Безопасность

Пароль вводится на Mac, а не на телевизоре, и не отправляется на GitHub. Но **он записывается в персональный WGT**. Кто получит файл, сможет извлечь пароль. Не прикладывай такие WGT к Issues и не публикуй в Releases. Лучше используй отдельную учётную запись Navidrome с ограниченными правами.

Если сменишь пароль или адрес сервера, **собери WGT заново и переустанови приложение**.

## Если что-то пошло не так

- Музыка не играет — попробуй HTML5 и проверь эту же песню во встроенном браузере Samsung.
- Пароль не виден при вводе — так и должно быть.
- Не получается установить приложение — проверь Developer Mode, IP компьютера и подпись WGT.
- Пользуешься Windows — смотри раздел [Windows / WSL](INSTALLATION.md#windows), он пока не проверен на реальном устройстве.
